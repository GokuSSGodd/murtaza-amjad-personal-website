SendIt — Cross-Platform P2P File Transfer

Architected a cross-platform peer-to-peer file transfer system spanning iOS, Android, and desktop, eliminating reliance on third-party cloud storage. Built with a JavaFX desktop client, native SwiftUI and Kotlin mobile clients, and a Spring Boot backend. Core functionality is complete — now in a UI/UX redesign pass ahead of public launch on the Apple App Store, Google Play, and Microsoft Store.

⬡ Co-led development of a native iOS client in SwiftUI, owning the sender-side flow and encryption implementation
⬡ Built the Android UI in Kotlin, handling core screens and navigation
⬡ Designed a WebSocket-based relay architecture with end-to-end encryption, preventing persistent server-side file storage
⬡ Implemented JWT-based authentication with role-based access control for encrypted multi-client sessions
⬡ Configured GitHub Actions CI/CD pipelines to automate build and test workflows
